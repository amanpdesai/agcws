# Upstream baseline code

These pinned submodules support the maintained implementations in
[src/agcws/baselines](../../src/agcws/baselines/).

- `gest/` supplies hash-checked genetic operators used by the GeST bridge.
- `gest_saga/` supplies components exercised by upstream contract tests.

The final phase-GA and phase-model policies are adaptations implemented in this
repository, not executions of the upstream hardware runners.
