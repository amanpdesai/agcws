# Paper evidence

These small files connect the paper to the full archives in [results](../../results/).

| File | Purpose |
| --- | --- |
| `figure_recipe.json` | Fixed examples, archive paths and selection rules |
| `mesh_examples.json` | Extracted workloads, activity and proposal counts |
| `task_vectors.json` | Frozen targets, scales and source hashes |
| `task_vectors.md` | Readable target table |
| `build_provenance.json` | Hashes of the last build's inputs and outputs |

The [build](../README.md#build) regenerates extracted data and the receipt.
Change the recipe deliberately, but do not hand-edit extracted measurements.
