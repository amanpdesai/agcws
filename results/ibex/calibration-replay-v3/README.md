# Ibex calibration bridge to the longer-window runtime revision

Replay of the full original 64-case calibration on the runtime that introduces
RedMulE's independent longer-window domain. All 64 cases match in the complete
decoded-waveform comparison, excluding only the VCD header date block.
Strict raw-file hashes still differ for valid recordings and remain recorded.

`waveform-audit.json` in the evidence archive binds its receipt to the driver,
configuration, complete records and both manifests. Eight decoder processes
accelerate the same comparison; no signal or timestamp data is discarded.

Compressed config/freeze/spec sidecars preserve the original parent-directory
inputs. This bridge supports bank admission, not a new policy result.
