# Ibex fixed operation diagnostic

All 88 predeclared programs passed the existing architectural and useful-work
checks. Fixed division operands create substantially lower activity than the
other tested single-operation bodies. For example `divu-1-8` produces roughly
63 transitions/edge while executing divisions, followed by a higher-rate
polling tail; its full-window mean is 216.73. This identifies candidate building
blocks for witness construction, not qualified targets or an agent result.

The config, driver freeze and reference spec accompany `evidence/`. The archive
retains profiles, execution diagnostics, assembly, architectural checks and all
measurements. No requested target or tolerance changed. The new Ibex bank still
qualifies two nonflat requests per split and neither control. Historical Pro
results use a different bank.
