# RedMulE coarse timing: no new qualifications

The predeclared four-round release-coordinate procedure completed all eighteen
requests. It tried plus/minus 8192, 4096, 2048 and 1024-cycle moves without
clipping invalid proposals or changing jobs, operands or targets. Development
remains 2/8 nonflat plus control; confirmation 7/8 plus control. No new target
qualified. This is not proof of infeasibility.

`audit.json` reconstructs proposal enumeration, parent replay, strict stopping,
cached outcomes and best-parent choices. `evidence/` preserves all rounds and
rejections. The original bank and lineage are retained in `config.json`.
This is a target-informed feasibility search, not a paper baseline comparison.
A longer-window measurement version has been proposed for user direction;
the existing measurement contract has not been changed.
